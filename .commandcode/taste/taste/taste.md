# Taste
- Communicates in Italian; expects replies in Italian. Confidence: 0.95
- Prefers to be guided step-by-step through deployment/platform procedures ("puoi guidarmi?") rather than having actions performed on their behalf. Confidence: 0.7
- For web-UI steps, wants the assistant to hand over the exact ready-to-paste content as a verbatim code block ("incolla TU PER ME") so they can copy it as-is into GitHub/web forms, instead of being told what to write themselves. Confidence: 0.5
- Prefers creating/editing repo files via the GitHub web UI (Add file → Create new file, commit directly to main) instead of using local git operations. Confidence: 0.6
- When migrating a project to a new platform, wants the new deployment config to be an exact replica of the previous working setup (e.g., Railway's Node 20, prod-only deps, no Next.js build) rather than a redesign; on a new platform (Northflank) he again pasted the Railway-style Dockerfile (including `pnpm install --prod`) and asked to confirm it, showing he expects the new platform to accept the old working config as-is. Confidence: 0.7
- Delegates hands-on repo/deploy-file work to the agent ("fallo tu per me"): after agreeing on the file content, expects the agent to create/edit the file locally, commit to main, push, and restore the working branch — not just hand over instructions or paste-ready content for the user to apply. Confidence: 0.7
- When asked to verify/test functionality, prefers the agent to create and run a complete automated test suite (unit + integration) covering the feature's behaviors rather than guiding them through manual/click-through procedures; expects the suite to be actually executed, failures fixed, and results reported. Confidence: 0.7
- Before executing fixes for failing tests/bugs, wants the agent to analyze the root cause and propose solution options first, then wait for approval ("fai una analisi ... e dimmi che soluzioni proponi prima di eseguire le correzioni"); expects options with a recommendation and a go-ahead before any code change. Confirmed again when the user approved the recommended fix with a one-word "si" and only then let the agent apply it. Confidence: 0.95
